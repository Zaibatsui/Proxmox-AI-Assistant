<product_requirements>
The overarching goal is an AI-powered Proxmox assistant capable of hardware monitoring, misconfiguration detection, LLM-based fixes, and verified command execution via a web UI. This evolved to include real Proxmox integration, AI actions via SSH, theme/branding, per-user OpenAI keys, Docker updates, version display, and extensive UI/UX improvements.

Recent, explicit requirements focused on:
1.  **AI File Access**: AI must access files on the Proxmox host and *inside* VMs/containers (e.g., , Docker compose files).
2.  **AI Confirmation Workflow**: AI proposes actions, allows user edits, and requires explicit confirmation for execution.
3.  **Backup/Restore System**: User-friendly labeled backups and restore functionality from a list.
4.  **UI/UX Improvements**:
    *   **Settings Page**: Collapsible cards (all by default), consistent AI Config styling, full-width Proxmox/SSH cards, How to create API token guide integrated.
    *   **File Browser**: Display files from specific VM/Container locations, with a FileZilla-like dual-pane interface for navigation, upload/download, and reliable preview, with AI-aware connections.
    *   **AI Assistant**: Location selection dropdown for AI context, responsive chat interface with always-visible input, scrollable history.
    *   **SSH Connection Test**: Test VM/container SSH credentials *before* modal close.
    *   **Dashboard Redesign**: More relevant, compact, visually appealing with real-time connection status indicators for Proxmox API, SSH, and OpenAI API (configurable: real-time for Proxmox/SSH, config status for OpenAI).
    *   **VM Management**: Display individual systems on separate, visually distinct cards.
5.  **Advanced App Appearance**: Intermediate to advanced control over app appearance (color schemes, background/card styles, layout density, border radius, shadow intensity, sidebar width) with live preview and persistence.
6.  **Login/Credentials**: The application should allow user registration, and AI should correctly store/use provided VM SSH credentials.
